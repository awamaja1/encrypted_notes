## 🔑 KEY DIFFERENTIATORS (Jawaban Cepat untuk Juri)

**Q: Kenapa ICP bukan Ethereum?**
A: ICP = full-stack on-chain (frontend+backend+storage). Ethereum = only smart contracts. Use case kami butuh encrypted storage.

**Q: Bagaimana keamanan data?**
A: vetKD threshold cryptography. Data encrypted client-side. Bahkan kami tidak bisa baca.

**Q: Siapa kompetitor?**
A: Belum ada yang fokus creative IP di Indonesia. Indirect: Google Drive (centralized), NFT platforms (speculation), Notary (offline).

**Q: Business model?**
A: Freemium. Free basic, Premium Rp 99K/month (legal cert, unlimited storage, AI advanced).

**Q: Compliance OJK?**
A: UU Hak Cipta No. 28/2014 compliant. Future: OJK Innovation Sandbox untuk ckBTC payments.

**Q: Adoption strategy?**
A: Phase 1: Tech communities. Phase 2: BEKRAF partnership. Phase 3: Mainstream PR & ads.
